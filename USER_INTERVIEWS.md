# USER_INTERVIEWS.md

## 1. Rahul K — Freelance Developer / Final Year CS Student

Talked over Discord for around 10 mins. Rahul does freelance MERN projects and uses Claude + Copilot regularly.

He said he mostly buys AI tools because “everyone on X keeps posting insane workflows.” He was using both Claude Pro and ChatGPT Plus at one point but cancelled Claude after realizing he barely opened it outside coding sessions.

Some things he mentioned:

> “I lowkey mainly use claude for everything so i dont have to keep track of many tools.”

> “Other than claude i use the student plans for github copilot and chatgpt go and gemini so i dont have to pay for anything.”

> “Most people are honestly just experimenting and stacking subscriptions.”

One thing I didn’t expect was him saying he sometimes shares subscriptions with friends because paying separately for every AI tool feels excessive as a student.

This changed how I thought about recommendations in the audit. Initially I was only thinking about companies/startups, but after this I added logic around individual usage and smaller teams. I also made the tone less finance-heavy and more practical.

## 2. Neeraja T — Indie Hacker / College Senior

Met through college startup community. Mostly builds side projects and experiments with new AI coding tools constantly.

She currently uses Cursor Pro, ChatGPT Plus, and Gemini API occasionally for testing.

Some quotes from the conversation:

> “I mainly use student free plans like GitHub Copilot student plan and stuff.”

> “I don’t like too many subscriptions.”

> “I don't think people are going to post audit results of how they are wasting money on tools.”

That changed how I approached the recommendations section. Instead of always forcing savings opportunities, I added cases where the audit can honestly say the user’s current setup already makes sense.
