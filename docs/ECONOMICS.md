# Unit Economics

## Cost of Acquisition (CAC)
- **Tool Cost:** $0 to build (in-house engineering).
- **API Costs:** Groq API / Anthropic API for the summary generation. ~$0.001 per audit.
- **Hosting:** Vercel (Free tier initially, $20/mo Pro).
- **Database:** Supabase ($25/mo Pro tier).

Total Marginal Cost per Audit: **~$0.005**

## Customer Lifetime Value (LTV)
- If an audit identifies $1,000/mo in savings, and we capture them as a Credex customer, we sell them $1,000 worth of AI credits for $600.
- Credex margin is ~20%. Profit = $200/mo.
- Average customer lifespan: 12 months.
- LTV = $2,400.

## ROI
With a CAC approaching $0 (organic via the tool) and an LTV of $2,400+, the unit economics are extremely strong. The audit tool serves as an automated, highly scalable SDR.
